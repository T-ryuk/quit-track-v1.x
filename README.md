# Quit Track
First native Android functional prototype.

Included:
- 40-day counter
- local smoking/craving storage
- chronological entries
- craving intensity 1–10
- basic statistics
- emergency 10-minute timer
- reset controls

This is a foundation. The exact 40-day SMART chronology, targets, daily review, robust offline behavior, and export/import should be implemented and tested before release.

Open in Android Studio and build with `assembleDebug`.
